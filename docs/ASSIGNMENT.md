# Grow My Therapy — Stage 2 Internship Assignment

## Role
Front-End Developer Intern

## Objective

Clone the homepage of:

https://www.conejovalleycounseling.com/home

Then redesign it using a new theme, new copy, new images, and an imaginary therapist profile while preserving the original homepage's layout and structure.

## Required Tech Stack

- Next.js
- Tailwind CSS
- TypeScript
- Responsive design
- Reusable components

Component libraries are allowed.

AI tools are allowed and encouraged, but AI output must be intelligently reviewed and refined rather than blindly copied.
